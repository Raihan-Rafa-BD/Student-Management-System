**Student Management System:**
A simple Python Student Management System built to demonstrate important Object-Oriented Programming (OOP) concepts, including encapsulation, inheritance, polymorphism, method overriding, super(), and variable-length arguments.

#Overview:

This project defines a base Student class and two specialized classes:
    UndergraduateStudent
    GraduateStudent

The program stores student information, manages student marks, calculates results, assigns grades, and displays student-specific information.

It is designed primarily as an OOP practice project for Python beginners.
#Features

  1.Store student information,
  2.Store student ID,
  3.Get and update student email etc. 
  4.Demonstrate variable-length arguments using *args

#Technologies Used:
    Python 3
    Object-Oriented Programming (OOP)

No external libraries or dependencies are required.
